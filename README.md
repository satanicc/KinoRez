# KinoRez — гид по Diablo Immortal

Веб-гид по Diablo Immortal: прокачка, снаряжение, легендарные камни и сборки
по всем классам, с персональным профилем персонажа.

## Возможности

- **Профиль** — выбираешь класс, вводишь уровень, резонанс, Paragon и уровень
  Ада, отмечаешь, какие универсальные легендарные камни уже есть. Всё
  сохраняется в браузере (localStorage).
- **Прокачка** — пошаговый чек-лист от 1 до 60 уровня и что делать сразу
  после достижения эндгейма.
- **Снаряжение** — объяснение механик редкости предметов, резонанса,
  пробуждения и рангов легендарных камней + список универсальных камней,
  полезных почти любому классу.
- **Классы и сборки** — по всем 8 классам (Варвар, Некромант, Охотник на
  демонов, Чародей, Монах, Крестоносец, Кровавый рыцарь, Буря): роль, ключевые
  умения, 1–2 направления сборки со списком приоритетных характеристик.
- **Рекомендации** — на основе твоего профиля гид подсказывает следующий шаг:
  что фармить, каких камней не хватает, когда пора открывать следующий
  уровень Ада.

## Запуск

Статический сайт без сборки и зависимостей. Достаточно открыть `index.html`
в браузере, либо поднять любой локальный сервер, например:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Важно

Игра регулярно получает балансные патчи. Механики (резонанс, пробуждение,
ранги камней) стабильны годами, но точные названия сетов/легендарок и их
бонусы всегда сверяйте с тултипом прямо в игре или актуальными гайдами
сообщества.
