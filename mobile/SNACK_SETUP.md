# КиноРез для Snack (Expo Go 57)

## Быстрый Старт

### На телефоне:

1. **Открой браузер** и перейди сюда:
   ```
   https://snack.expo.dev
   ```

2. **Создай новый Snack** (если нужно)
   - Нажми "Create a Snack"
   - Войди в аккаунт (бесплатно)

3. **Скопируй код из App.js** из этого репозитория:
   - https://github.com/satanicc/KinoRez/blob/claude/movie-streaming-app-eghbsk/mobile/App.js

4. **Удали весь старый код в Snack** и вставь новый

5. **Открой app.json в Snack и убедись, что там:**
   ```json
   "sdkVersion": "57.0.0"
   ```

6. **Жди компиляции** (может занять минуту)

7. **Когда появится QR код справа** - сканируй его в Expo Go

## Решение Проблем:

### "Unsupported SDK (54)"
**Решение:** Проверь app.json, там должно быть:
```json
"sdkVersion": "57.0.0"
```

### "Код не компилируется"
**Решение:**
1. Убедись что это plain JavaScript (не TypeScript)
2. Удали все типы (`:` и типы переменных)
3. Используй только React Native компоненты

### "QR код не появляется"
**Решение:**
1. Жди 1-2 минуты
2. Обнови страницу (F5)
3. Проверь консоль (есть ошибки?)

### "Приложение зависает"
**Решение:**
1. Закрой Expo Go
2. Скачай заново из Play Store
3. Перезагрузи телефон
