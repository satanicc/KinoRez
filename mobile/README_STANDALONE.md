## Быстрый Старт (2 минуты)

### 1️⃣ Установи Expo Go на телефон

- Открой **Google Play Store**
- Ищи **"Expo Go"** (официальное приложение)
- Нажми **Установить**

### 2️⃣ Открой KinoRez в Expo Go

Два варианта:

**Вариант A: Через QR код**
1. Откройте Expo Go на телефоне
2. Нажми "Scan QR Code"
3. Отсканируй этот QR код:
```
[QR код будет добавлен позже]
```

**Вариант B: Через приложение**
1. Открой Expo Go
2. Ищи "KinoRez" в Published apps
3. Нажми чтобы открыть

### 3️⃣ Готово!

Приложение загружается... Жди 30-60 секунд. Приложение запустится автоматически!

## Решение проблем

### "Не могу найти KinoRez в Expo Go"

Попробуй:
1. Перезагрузи Expo Go
2. Проверь интернет соединение
3. Используй QR код

### "Видео не открывается"

Решение:
1. Проверь интернет
2. Попробуй другое качество
3. Откройте в браузере вручную

### "Поиск не работает"

1. Проверь интернет
2. Попробуй другое название
3. Перезагрузи приложение (Shake → Reload)

### "Приложение зависает при загрузке"

1. Закрой и открой Expo Go заново
2. Перезагрузи телефон
3. Очистить кэш Expo Go

### "Нужна помощь в Expo Go"

В приложении Expo Go:
- Shake Device → Help
- Это откроет меню помощи

## Клавиши (когда приложение открыто)

- **Shake телефон** - Меню Expo
- **Press R twice** - Reload
- **Press 'j'** - Debugger
