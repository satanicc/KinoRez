# KinoRez — PRD

## Original Problem Statement
Пользователь сделал мобильное приложение-каталог фильмов/сериалов «KinoRez» (был HTML-прототип) и хочет подключить реальную базу фильмов и сериалов с оригинальными постерами, сохранив все существующие экраны.

## User Choices
- Источник данных: **TMDB** (v3 API key, в `backend/.env` → `TMDB_API_KEY`)
- Язык интерфейса и данных: **Русский** (`language=ru-RU`)
- Задача: интегрировать реальную базу в существующий UI, экраны не менять
- Экраны: все как в прототипе

## Architecture
- **Backend** (FastAPI) — прокси к TMDB (`requests`, sync-эндпоинты), нормализация в единый формат с реальными URL постеров/бэкдропов, RU-локализация стран/жанров.
  - `GET /api/home?kind=all|tv|movie|anime|cartoon`
  - `GET /api/search?q=`
  - `GET /api/collections`, `GET /api/collections/{key}` (10 кураторских подборок через discover)
  - `GET /api/detail/{movie|tv}/{id}` (жанры, страна RU, рейтинг, голоса, длительность, возраст, описание, актёры до 12, похожие до 12, YouTube-трейлер, сезоны/серии)
- **Frontend** (Expo Router, React Native) — точная пересборка KinoRez:
  - Кастомный плавающий pill-таббар (Главная/Подборки/Профиль) + отдельная круглая кнопка поиска (FAB)
  - Тема: тёмная, акцент красный `#e6402f`, золото `#e8b64c`
  - Локальное хранилище (`@/src/utils/storage`) для закладок, истории и профиля

## User Personas
- Русскоязычный зритель, ищет фильмы/сериалы/аниме, сохраняет закладки, продолжает просмотр.

## Core Requirements (static)
- Реальные данные и постеры TMDB на русском
- Все экраны прототипа: Главная, Подборки, Профиль, Поиск, Детали, Плеер, Авторизация
- Закладки/история/профиль сохраняются локально

## Implemented (2026-07-13)
- Полный бэкенд-прокси TMDB (home/search/collections/detail) — протестирован (21/21 pytest).
- Главная с фильтр-чипами и 3-колоночной сеткой реальных постеров + рейтинги.
- Подборки (10 шт.) → детальная подборка.
- Поиск (debounce, реальные результаты).
- Экран деталей: hero-бэкдроп, метаданные (RU), статистика (TMDB/Оценки/Длительность/Возраст), описание, актёры, похожие; лист «Смотреть» (озвучка/сезон/серия/качество) → Плеер.
- Плеер: реальный YouTube-трейлер через WebView (+ graceful fallback «Трейлер недоступен»).
- Профиль: карточка аккаунта, листы Досмотреть/Закладки/Обновления сериалов; вход/регистрация (локально).
- Закладки и история сохраняются локально и отображаются в профиле.
